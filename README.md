# Welcome to InvenPlus

This is a mono repo for an inventory system for a small textile garment. 

---

## Frontend
This is a NextJs frontend

To develop on the frontend please do the following

```shell

cd ./frontend

# install packages
npm install

#run the dev server
npm run dev
```

## Backend
This is a Django Rest Framework backend

To develop on the backend please do the following

```shell

cd ./backend

# more to follow later.

```
